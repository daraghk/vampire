# Vampire 5.0 Results — GRP Problems (655 problems)

## Overview

This dataset contains the logs of our concurrent framework running default **Vampire 5.0** on **655 problems** from the **GRP (Group Theory)** domain of the TPTP library (v9.2.1).

Runs were conducted with a **60-second timeout** per Vampire invocation.

## Results summary

- **463 / 655** problems had at least one successful proof.
- **192 / 655** problems had no proof found within the timeout.

## Directory structure

Each problem has its own timestamped folder:

```
<timestamp>_<problem>/
├── <timestamp>_<problem>.log   # Full pipeline log
├── clausified/                 # Clausified version of the original problem -- Ignore
│   ├── <problem>_clausified.p
│   └── <problem>_clausified_axioms.p
├── variants/                   # Generated variant formulations
│   ├── variant_0.tptp          # Clausified variant with LLM seeds -- Ignore
│   ├── variant_0_original.tptp # Non-clausified variant with LLM seeds
│   ├── variant_1.tptp
│   ├── ...
│   └── variant_N_original.tptp
└── results/                    # Vampire output for each run
    ├── summary.json            # Machine-readable outcome summary
    ├── original.out            # Vampire output on original problem
    ├── original_clausified.out # Vampire output on clausified problem
    ├── variant_0.out
    ├── variant_0_original.out
    └── ...
```

## Run configurations evaluated

For each problem, Vampire was run in parallel on several configurations:

| Configuration | Description |
|---|---|
| `original` | The unmodified TPTP problem file |
| `original_clausified` | The problem after clausification by Vampire | -- Ignore
| `variant_N` | Clausified axioms + LLM-generated seed clauses + negated conjectures | -- Ignore
| `variant_N_original` | Original (non-clausified) problem + LLM-generated seed clauses |

### Note on clausified variants

The `original_clausified` run and the clausified `variant_N` (without the `_original` suffix) configurations **are not part of the results reported in the paper**. They were included in the experimental pipeline for exploratory purposes. The paper reports results only for the `original` and `variant_N_original` configurations, which operate on the original (non-clausified) problem formulations augmented with LLM-generated seed clauses.

## Variant generation

- **3 variants** were constructed per problem using the `all` strategy (full axiom base).
- **5 seed clauses** per variant were generated by **gpt-5-mini** (`gpt-5-mini-2025-08-07`).
- Seed clauses were verified for entailment before inclusion.

## Log format

Each `.log` file records the full pipeline execution:

1. **Clausification** of the input problem.
2. **Variant construction** — selection of the axiom subset (B_i), LLM seed generation prompts/responses, and entailment verification of each seed.
3. **Parallel evaluation** — Vampire is invoked on all configurations simultaneously, with per-run status (`PROVED` / `TIMEOUT` / `UNKNOWN`) and wall-clock time.
4. **Evaluation summary** — aggregated counts of proved, timed-out, and unknown runs.

## Reproducibility

- **Prover:** Vampire 5.0 (built from source)
- **LLM:** gpt-5-mini-2025-08-07
- **Timeout:** 60 seconds per run
- **Problem source:** TPTP v9.2.1, GRP domain
